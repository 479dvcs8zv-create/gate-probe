## 題目（整段貼給 Gemini，並附上 taiex_usd.csv）

```
第 28 輪：用附件 taiex_usd.csv 跑兩個回測。請用 Python 實際執行，回覆完整程式碼與輸出。

【規矩，必須遵守】
1. 只用附件資料。不得使用任何外部資料、記憶中的數字或自行補值；缺的資料就跳過並在輸出中計數。
2. 規則照下面寫的做，不得自行調整參數或另找「更好」的參數。
3. 不得偷看未來：每個訊號只能用當時已經公布的資料（見美元指數延遲規則），結果用訊號「之後」的價格計算。
4. 回覆必須包含：(a) 完整可執行的 Python 程式碼（一個檔案，只用 pandas、numpy）；(b) 程式的完整輸出；(c) 資料起訖日期與筆數；(d) 隨機 5 個訊號日的明細（日期、美元指數值、零軸值、加權指數收盤），方便抽查。
5. 數字只寫程式輸出的結果，不要四捨五入以外的任何修改；不要寫「大約」。

【資料說明】
欄位：date, taiex_close（證交所加權指數收盤，價格指數、不含股利）, dtwexafegs（美國聯準會先進經濟體美元指數）, dtwexbgs（廣義美元指數）。美元指數沒有值的日子是空白。
美元指數延遲規則：日期 d 的美元指數值，要到 d 之後第 8 個日曆日（含）以後的第一個加權指數交易日才算「已知」（聯準會每週一公布上週資料，保守處理）。

【回測一：美元指數零軸訊號】
1. 用 dtwexafegs 的實際觀測日計算零軸值 Z：Z = (今天值 − 前 20 個觀測的最高值) ÷ (前 20 個觀測的最高值 − 最低值) × 100；「前 20 個觀測」不含今天。最高等於最低時 Z 記為缺值。
2. 依延遲規則把 Z 對應到加權指數交易日（每個交易日用當時已知的最新 Z）。
3. 訊號 A：Z 由 ≤ 0 變成 > 0 的那一天（突破 20 日高點）。狀態 B：Z > 0 的所有日子。狀態 C：Z < −100 的所有日子。
4. 對每一種，計算之後 20 個交易日、60 個交易日的加權指數報酬，以及之後 60 個交易日內的最大跌幅；和「全部交易日」的同樣統計比較（平均、中位數、上漲比例、筆數）。
5. 訊號 A 另外計算「彼此相隔至少 20 個交易日」的獨立事件數與其平均報酬（避免重疊樣本誇大）。
6. 分三段報告：2006–2015、2016 至資料結束、全期。
7. 用 dtwexbgs 重做一次 1～6，並列比較。

【回測二：加權指數均線濾網】
1. 每天收盤後：加權指數收盤 ≥ N 日均線 → 隔一個交易日起持有 100%；< N 日均線 → 隔一個交易日起持有 0%（現金報酬 0）。N = 60 與 240 各做一次。
2. 每次由 0% 變 100% 或 100% 變 0%，扣交易成本：買 0.1425%、賣 0.1425%＋0.1%。
3. 與「一直持有 100%、不扣成本」比較：年化報酬、最大跌幅、年化波動、切換次數、持有時間比例。
4. 分 2006–2015、2016 至結束、全期三段報告。
5. 另外做「0% 改成 50%」的版本（跌破均線時只持有一半）。交易成本只對實際買賣的部分計算（例如 100%→50% 只對一半部位扣賣出成本）。
6. 回測二只用 taiex_close 有值的列；美元指數欄位在回測二完全不用。
```
