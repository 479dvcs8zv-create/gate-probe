規則事先寫在 `tools/round49_rating_ladder_backtest.py`（commit 2d89640，看結果前提交）。

**照事先寫的標準：不通過**（2019 年後中間兩級 C、B 順序倒過來）。**A、B+ 要合併**（2019 年後沒差別）。
