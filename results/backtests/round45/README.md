# 第 45 輪：投本比（2026-11-27）

規則事先寫在 `tools/round45_trust_ratio_backtest.py`（commit 6017168，看結果前提交）。對照組 `tools/round45b_trust_ratio_control.py` 是**看過結果才加**的，不改判斷。

**照事先寫的標準：通過。但對照組顯示優勢多半不是來自「投信買」，實際用處很小。**

資料：上市普通股 2012-05～2026-10；投信買賣超＝證交所 T86；發行股數＝證交所 MI_QFIIS 每月第一個交易日（174 個月全部成功）；
進場＝訊號隔天收盤；超額＝減去同期全部合格上市股票等權平均。抽 5 筆事件從原始資料重算投本比，全部相同。

60 日平均超額（± 標準誤）：

| 組別 | 2012–2018 | 2019–2026 |
|---|---|---|
| 投本比突破 +1%（事先寫的主組） | +1.6% ± 1.2 | +2.6% ± 1.9 |
| 投本比跌破 −1%（投信大賣） | +0.6% ± 1.1 | +2.3% ± 1.4 |
| 有投信資料的一般日子（對照，事後加） | +0.0% ± 0.1 | +0.1% ± 0.2 |
| 投信幾乎沒進出（\|投本比\| < 0.2%，對照，事後加） | −0.2% ± 0.2 | −0.4% ± 0.2 |

- 事先寫的兩個條件兩段都達到：60 日超額 ≥ +1 個百分點、20 日超額 > 0（+0.9%、+0.7%）。
- 但投信「大賣」的股票之後也贏大盤。「買」減「賣」只剩 60 日 +1.0、+0.4 個百分點；2019 年後 20 日是 −0.1。
- 所以強的主要是「投信大量進出的股票」，不分買賣；投信買進本身的訊號很弱。主組離 0 也不到 1.5 個標準誤。
- 市值 < 100 億：20 日 −0.0%、60 日 +0.9%，沒有優勢。
- 2025 年起（主動式 ETF 也算投信）：買 +8.3% ± 6.0、賣 +6.0% ± 3.4，只有 19 個月，誤差很大。
