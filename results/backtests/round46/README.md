# 第 46 輪：季線轉彎（扣抵價）當出場訊號（2026-11-27）

規則事先寫在 `tools/round46_ma60_slope_exit_backtest.py`（commit 7b69533，看結果前提交）。

**結論：不支持，維持「收盤跌破季線就賣」。**

樣本：上市＋上櫃 2010～2025（之後要有 250 天資料），站上季線 20 天且季線上彎的起點共 26,264 次。看 250 天、賣了不買回。

| 做法 | 2010–2017 平均／最差 10% | 2018–2025 平均／最差 10% | 和現行比出場時間 |
|---|---|---|---|
| A 跌破季線就賣（現行） | +0.6%／−11.0% | +2.2%／−12.1% | — |
| B 季線下彎就賣（＝跌破扣抵價） | +0.7%／−14.3% | +3.1%／−15.2% | 平均晚 13 天（八成比較晚） |
| C 跌破季線而且季線下彎才賣 | +1.0%／−14.8% | +3.7%／−15.8% | 平均晚 21 天 |
| D 兩個任一先到就賣（只列數字） | +0.6%／−10.8% | +1.9%／−11.7% | 平均早 3 天 |
| 不賣抱 250 天（參考） | +3.7%／−37.6% | +18.2%／−31.7% | — |

- 季線下彎通常比跌破季線**晚**出現，不是提早警告。
- B、C 平均多一點（0.1～1.6 個百分點），但最差 10% 多虧 3.3～3.7 個百分點，沒達到事先寫的標準（平均 +1 個百分點、最差不多於 2 個百分點）。
- 扣抵價可以在網站「只顯示」，用來預告季線什麼時候會轉彎，不當出場規則。
