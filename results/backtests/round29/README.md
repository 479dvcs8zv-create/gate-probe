## 換算成持股比例（2007-12～2026-10）

| 做法 | 年化報酬 | 最大跌幅 | 一年調整次數 |

## 結論

1. **用這 4 項合計天天調整持股，沒有比固定 65% 好**：報酬少 0.3～1 個百分點、跌幅只少一點、調整太頻繁。
2. 擁有者的「平時 60～70%、最少 20～30%」本身就有效：固定 65% 把最大跌幅從 −56% 降到 −41%。
3. 真正有用的是極端訊號：**恐慌時不要減碼**（之後 60 日平均 +9.3%）；合計 ≤ −2 時之後跌幅明顯較大（樣本少，多在 2008～2015）。
4. 建議：持股比例平時固定在基準，**只在極端時調整**（恐慌 → 不減碼；合計 ≤ −2 → 降），−1～+1 只顯示不動持股。換算數字仍需擁有者核准。
