事先寫定的判斷：
1. 降級減碼有沒有用（最差 10% 少賠 ≥ 0.5 點、平均少不到 0.3 點，兩段）：2019–2021 成立；2022– 平均少 0.30 點，剛好沒過 → **不成立（差一點）**。最差 10% 兩段都少賠約 1.5 點。
2. 降級全出比減半好：**不成立**（最差 10% 再少賠約 1 點，但平均再少 0.13～0.24 點、賠錢次數變多）。
3. 評級挑股：**不成立**（便宜組和貴組差不多，同第 42 輪）。

結論：每多加一層風險控制，平均報酬少約 0.15～0.3 點，最差 10% 少賠約 1～1.5 點；是「要穩還是要多賺」的取捨，不是白賺。這幾年大多是多頭，一路抱著的平均報酬遠高於這些做法，但最差 10% 會賠 18～24%。
