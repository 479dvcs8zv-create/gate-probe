## 事先寫定的判斷
1. 評級有沒有用（便宜組 − 貴組 ≥ +1 點，兩段）：**不成立**（−0.17、+0.30 點）。用擁有者的算法（G_CRASH_ma）也一樣，便宜組甚至比較差。

3. 拿掉「賺 5% 先賣 4 成」：**成立**（兩段平均多 0.4～0.6 點，最差 10% 一樣）。
4. 和抱 120 天比：只列數字。抱 120 天平均高很多，但最差 10% 賠 18～24%、約一半賠錢；2022 後便宜組的最差 10%（−18.4%）比貴組（−24.2%）輕，和第 38 輪「便宜股回檔風險較低」一致。
