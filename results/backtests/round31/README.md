# 第 31 輪：網站「台股總經與市場位階」分數 20 年重建 → 只在極端時調整持股（Claude 2026-10-26）

擁有者 10-20／10-21：持股「固定基準 60～70%、下限 20～30%，只在極端時調整」，而且「以全市場經濟指標為主，不是單一指標決定持股」。

## 結論（待擁有者核准）
1. 網站的總經分數是「描述現況」的指標，**落後股價、很少到極端**；拿它判斷「極端」來調持股，20 年中不是沒觸發，就是在低點附近減碼、在高點附近加碼，結果都比固定 65% 差。
2. 擁有者的「平時固定 60～70%」本身就有效：固定 65% 把 20 年最大跌幅從 −58% 降到 −43%（2016 年以後從 −32% 降到 −22%）。
3. 與第 29 輪一致：恐慌、分數低的時候**不是**減碼訊號。
4. 專業機構也是固定基準＋小幅偏離（Gemini 第 31 輪：挪威 GPFG ±2%、日本 GPIF 股票合計 ±9%、CalPERS ±7%、戰術配置常見 ±5～10%）。
5. **建議**：持股固定 65%（定期回到 65%），總經分數只顯示、不連動持股；下限 25% 暫不設自動觸發條件。網站不需要改程式。
