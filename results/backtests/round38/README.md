## 事先寫定的判斷

1. 成長率不設上限／擁有者 EPS：要兩段都比現行好 1 個百分點以上——**不通過**（不設上限 +0.06、+0.93；擁有者 EPS −0.88、−0.04）。維持現行 EPS 算法。
2. 股災本益比：擁有者 EPS 下，股災區間對 5 年區間 +0.46、−2.19——**不通過**。股災區間會把約一半股票評為「貴」。維持 5 年區間。
3. 估值分歧未評的股票：現行算法下便宜組 120 日超額 −2.74／−2.53（要 ≥0）——**不通過**，維持未評。
4. 均線：原本就貴、又跌破 20 日與 60 日線的股票，60 日超額 −3.19／−2.32，沒跌破的 +1.09／+1.79；半年內跌 3 成機率 18.0%／21.0%——**兩段一致，支持現行均線扣級**。

## 白話

- 本益比區間在台股這 7 年：評為「便宜」的股票，接下來半年**沒有比較會漲**（反而略差，但誤差大、不顯著）；它真正的用處是**風險**——便宜組半年內跌 3 成的機率約 8～10%，貴組約 15～18%。
- 擁有者的兩個改法都沒有比現行好；股災本益比太嚴（一半股票變「貴」），也沒帶來更好的報酬。
- 均線最有用：貴＋跌破兩條均線的股票，接下來 3 個月平均落後 2～3 個百分點，大跌機率最高。
- 限制：EPS 是現在版本（含事後更正）、以法定期限當公告日；本益比用未調整收盤÷近四季 EPS；金融業期限未另調；結果是整體平均，不代表個股。

- 平常時期跌到參考價以下：1 年後約一半仍虧損、3 成會再跌 3 成——多半是基本面在變差。
- 景氣高峰股（今年獲利遠高於過去常態）：今年 EPS 把參考價墊高，「便宜」容易是陷阱。
