# 第 39 輪：跌破季線出場後「站回就買回」（擁有者 2026-11-10 22:16「可以啊」）

規則在看結果前寫定、先提交（tools/round39_ma60_reentry_backtest.py，commit d5edb0b）。資料：上市＋上櫃 2010-01～2026-04 的出場事件 28,051 筆（還原價、收盤 ≥ 10 元、20 日均額 ≥ 1,000 萬；之後要有 120 個交易日）。

**事先寫定的判斷：不支持**（R5、R10、R20 都沒通過）。

120 個交易日後（平均／最差 10%／扣掉市場等權報酬後的平均）：

| 做法 | 2010–2017 | 2018– |
|---|---|---|
| 賣了不買回（OUT） | 0／0／−3.3 | 0／0／−9.0 |
| 沒賣一路抱（HOLD） | +3.2／−23.8／−0.1 | +8.6／−23.1／−0.4 |
| 5 天內站回就買、再跌破就賣（R5） | +0.1／−3.3／−3.2 | +0.8／−3.7／−8.3 |
| 20 天內站回就買、再跌破就賣（R20） | +0.1／−3.9／−3.2 | +1.2／−4.5／−7.8 |
| 5 天內站回就買、之後抱著（R5H） | +2.1／−15.1／−1.2 | +4.4／−14.3／−4.6 |

- 跌破後 5 天內就站回（假跌破）占 49%。
- 跌破季線之後，平均來說和大盤差不多（HOLD 超額約 0）；季線出場主要是避開最差的那 10%（−23%），代價是少賺大盤的平均漲幅。
- 站回就買、再跌破又賣：常常剛買回又跌破，來回被洗，平均只多 0.1～1.2 個百分點。
- 說明：事先寫的「中位數 > 0」這一條，因為約一半的事件沒有站回（報酬 0），本來就很難通過；不看這條，平均差距也很小，結論相同。
- 長榮航 2026-08-14 那次離現在不到 120 個交易日，不在這次的樣本裡。
